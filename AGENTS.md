# Repository Instructions

## Language

- Use English for all project content: documentation, code identifiers and comments, test names, CLI help and error messages, configuration comments, commit messages, and pull request descriptions.
- Keep user-provided text unchanged. The English requirement applies to project-authored content, not input passed to the CLI.

## Go Development

- Format Go files with `gofmt`.
- Prefer the standard library unless an external dependency solves a concrete need.
- Do not build the project after making changes.
- Use Conventional Commits. Do not add `Co-Authored-By` trailers or AI attribution.
